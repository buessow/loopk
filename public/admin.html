Agents (MCP)

An AI agent such as Claude Code, Codex (ChatGPT) or Gemini CLI can read the data through this server’s MCP endpoint: glucose, treatments, statistics such as GMI and time in range, the profile, the loop’s misses and what the algorithm computed at each run, and simulate other settings. It cannot change anything that reaches the phone; it may write the “AI Test” profile, which stays in loopk until an admin copies it into a real profile on the Profiles page. The button creates a read-only token for it and the commands that add the server to each agent; in the ChatGPT app, turn on developer mode (Settings → Apps → Advanced settings) and create an app with the URL and no authentication. Delete the token above to take the access back.

The same tools, run by the agent itself: it runs loopk’s MCP server in Node 20 or later on its own machine (with npx, which fetches it from this server), reads the data its token may read, and looks things up and simulates there, so this server only sends it the data and the code. For agents that start programs, such as Claude Code, Codex CLI, Gemini CLI or Claude Desktop; the ChatGPT app and other web clients cannot. The AI Test profile it writes is still saved here. It runs loopk’s current version at each start.

Follow a Nightscout server

Copies everything from a Nightscout server as it arrives there: glucose, treatments, loop status, profiles and heart rate. AAPS keeps uploading to that server. While following, this server takes no uploads itself. On the Nightscout server, create a token with the readable role (Admin tools → Subjects) and enter it here.

Sport mode

Adds a Sport button to the glucose page. Switching it on writes a Profile Switch to a percentage of the profile and an Activity temp target; switching it off goes back to the profile from before and ends the temp target. The duration is chosen when switching it on; with no limit it stays on until it is switched off (AAPS has no temp target without an end, so the temp target is then sent for 24 hours). AAPS applies them only with “Receive profile switches” and “Receive temporary targets” on in its NSClient settings: check on the phone that they arrived. A percentage below 100 lowers basal and makes ISF and carb ratio weaker by the same factor, so carbs are still counted right. Only admins can switch it.
